The three closing structures

Drag-along exists

Ideal

The OA lets the majority pull everyone into one deal.

  1. One signingTom, JJ&N, and the partners — same price, same day.
  2. Run the platformRenewal calendar, store buys, real estate.
Outcome100% on day one. Royalty steps 4% → 5% over ten years.

No drag, no block

Base case

Control transfers freely; the minority comes in on its own clock.

  1. Close 1Tom's 55%, JJ&N, and the license — together.
  2. Blended offer to the partnersTheir 45%, plus their two stores.
  3. Do they accept?
    AcceptStraight into the platform work.
    Hold outPatience — the first partner to sell wins.
  4. Run the platformRenewal calendar, store buys, real estate.
OutcomeSame platform, 6–18 months slower.

Transfers blocked / ROFR

Hard

No partial path — the OA forces a single, simultaneous deal.

  1. Five-party closeBret & Mike brought in early; everyone signs the same day.
  2. Run the platformRenewal calendar, store buys, real estate.
OutcomeSame platform, on an all-or-nothing closing day.

Every track ends in the same three moves — renewal calendar, store buys, real estate. The operating agreement never changes where the deal lands; it only decides how many closings it takes to get there.
